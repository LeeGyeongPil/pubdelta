# Sample data notice

The files in this folder are short excerpts of the CHANGELOG files published
with these packages on pub.dev. They are used only as practice (mock) data for
`pubdelta`; they are cut at the version that `example/pubspec.lock` pins.
Copyright belongs to the package authors; the license of each package applies
to its excerpt.
